🔧 AI chưa được bật. Để bật AI miễn phí (Groq - 14,400 req/ngày):
1. Truy cập console.groq.com/keys → đăng nhập → Create API Key
2. Copy key dạng gsk_...
3. Mở file .env → thay your_groq_api_key_here bằng key vừa tạo
4. Khởi động lại server: node server.js
Xin chào! Tôi là trợ lý MoodTok AI. Bạn có thể hỏi tôi về cách cải thiện giấc ngủ, giảm stress, hay bất cứ điều gì về sức khỏe tinh thần.
